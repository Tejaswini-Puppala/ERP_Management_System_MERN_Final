# ERP Management System

A full-stack **Enterprise Resource Planning (ERP) Management System** developed using the **MERN Stack**. The application helps manage products, parties, purchase orders, sales orders, invoices, goods receipt notes, and users through a centralized system.

## Project Overview

This ERP system provides a centralized platform for managing important business operations such as inventory, purchasing, sales, invoicing, and user management.

## Technologies Used

### Frontend

* React.js
* Vite
* JavaScript
* CSS

### Backend

* Node.js
* Express.js

* MongoDB

* JWT Authentication

## Environment Configuration

Create a `.env` file in the project root and configure the required environment variables.

An `.env.example` file is included in the repository as a reference.

**Do not share real passwords, database credentials, or secret keys publicly.**

## Installation

Clone the repository and install the required dependencies:

```bash
npm install
```

## Running the Application

Start the development server using:

```bash
npm run dev
```

Make sure MongoDB is running and the required environment variables are configured before starting the application.
